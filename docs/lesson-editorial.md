# Урок: редакционный контур, второе мнение Codex перед отдачей

После урока твои агенты перед отдачей текста, плана или кода показывают работу второй модели.
Claude делает, Codex (GPT по твоей подписке ChatGPT) проверяет, Claude правит и только потом отдаёт.
Для постов в канал есть два критика сразу: редактор сверяет текст с твоим стандартом, корректор ищет
ошибки языка.

## Что уже стоит после установщика

- Навык `codex-check` у Джарвиса и Кодера: `~/.claude-lab/<агент>/.claude/skills/codex-check/`.
- Скрипт двух критиков: `/usr/local/lib/<пользователь агентов>/text-critics.sh`.
- Настройки: `~/.claude-lab/shared/editorial.conf`.
- Пустой стандарт текста: `~/.claude-lab/shared/checklists/text-standard.md`.

Всё это выключено (`EDITORIAL_ENABLED=0`), пока ты не войдёшь в Codex. Выключенный навык отвечает
`verdict=DISABLED` и ничего не отправляет в модель.

## Что понадобится

1. Подписка ChatGPT: Plus или Pro. Отдельный API-ключ и оплата сверх подписки не нужны.
2. 10 минут.

## Шаг 1. Поставь Codex

На сервере под root:
```
npm install -g @openai/codex
```

## Шаг 2. Войди в Codex под пользователем агентов

Агенты работают под отдельным пользователем (`neurootdel` на новых серверах). Вход нужен именно под ним:
```
sudo -u neurootdel -H codex login --device-auth
```
Codex покажет ссылку и код. Открой ссылку в браузере, войди в свой ChatGPT и введи код. Проверка:
```
sudo -u neurootdel -H codex login status
```

## Шаг 3. Включи сверку

Открой `~/.claude-lab/shared/editorial.conf` пользователя агентов и поставь:
```
EDITORIAL_ENABLED=1
CRITICS_CONTEXT=Telegram-канал владельца онлайн-школы, для собственников школ, живым разговорным голосом автора
```
`CRITICS_CONTEXT` одна строка без кавычек: чей это текст, для кого, каким голосом. `CODEX_CHECK_MODEL`
оставь пустым, тогда Codex возьмёт модель по умолчанию для твоей подписки.

## Шаг 4. Заполни стандарт текста

`text-standard.md` пустой намеренно: там только общие шаги (заголовок, структура, язык, факты,
у цитаты всегда указан автор). Твои правила появляются из твоих правок. Каждый раз, когда правишь текст
агента, скажи ему: «запиши правку в стандарт текста». Через пару недель критики будут ловить ровно то,
что ловишь ты.

## Шаг 5. Проверь

Напиши Джарвису: «прогони сверку Codex на этом абзаце» и вставь короткий текст. В ответе должна быть
строка `Сверка Codex: APPROVE` или `REQUEST_CHANGES` с замечаниями. Для поста в канал:
«прогони двух критиков по черновику».

## Если что-то не так

- `verdict=DISABLED (нет входа в Codex)`: повтори шаг 2 под пользователем агентов.
- `verdict=EMPTY`: Codex не ответил (лимит подписки или сеть). Агент повторит один раз и отдаст с пометкой.
- Выключить обратно: `EDITORIAL_ENABLED=0` в `editorial.conf`.

У подписки ChatGPT есть лимит сообщений. Агент гоняет сверку только на том, что уходит людям, на служебных
ответах не гоняет.
