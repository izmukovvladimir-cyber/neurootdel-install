# Урок: Аудитор в твоём AI-отделе

После этого урока у тебя в отделе появится четвёртый агент, Аудитор. Он работает на своём движке Hermes и думает
моделью GPT через твою подписку ChatGPT. Его задача одна: проверять работу других агентов, пока она не ушла к
людям.

## Зачем он нужен

Агенты сами отчитываются о своей работе: «отчёт готов», «воронка настроена», «цифры собраны». Иногда в таком
отчёте ошибка: цифра взята не из кабинета, ссылка не открывается, бот отвечает не так, как написано. Аудитор
проверяет такие отчёты сам:

- открывает сам результат: файл, страницу, бота, таблицу;
- проходит путь клиента так, как его пройдёт живой человек;
- сверяет цифры с первоисточником;
- описывает найденный дефект так, чтобы его можно было повторить и исправить.

Аудитор ничего не чинит и не публикует. Нашёл проблему, описал, передал тебе или агенту, чья это работа.
Он думает другой моделью, поэтому ошибки Claude он замечает лучше, чем сам Claude.

## Что понадобится

1. Сервер, на котором уже стоит Нейроотдел (Jarvis и Richard работают).
2. Подписка ChatGPT: Plus или Pro.
3. Новый бот в Telegram только для Аудитора. Бот Jarvis, Richard или Coder для этого брать нельзя.
4. 15 минут.

## Шаг 1. Создай бота Аудитора

1. Открой в Telegram @BotFather и отправь `/newbot`.
2. Придумай имя, например «Мой Аудитор», и адрес бота, который заканчивается на `bot`.
3. BotFather пришлёт токен: строку вида `1234567890:AA...`. Сохрани её. Токен никому не пересылай и в чаты
   с агентами не вставляй.

## Шаг 2. Запусти установщик ещё раз

Зайди на сервер и запусти установщик этапа интенсива:

```
sudo bash /root/neurootdel-install.sh --stage intensive
```

На интенсиве у Coder и Аудитора по своему боту, установщик без них не продолжит. Если бота Coder ещё нет,
создай его так же, как в шаге 1 (урок docs/lesson-create-bots.md).

Установщик задаст знакомые вопросы. На уже заполненные просто нажимай Enter: всё, что записано на сервере,
сохранится. Когда он спросит токен бота Auditor, вставь токен из шага 1 и нажми Enter. Токен с ошибкой или
токен чужого бота установщик попросит ввести снова.

Установщик сам:
- поставит движок Hermes нужной версии;
- положит роль Аудитора в `/home/neurootdel/.hermes/SOUL.md`;
- включит три защиты: проверку фактов, запрет на выдачу паролей и ключей, режим «только чтение»;
- создаст мост, через который Jarvis и Coder отдают Аудитору задачи;
- создаст службы `hermes-auditor` и `hermes-auditor-bridge`.

В конце он напишет «Auditor installed». Если на твоём сервере пользователь называется `edgelab`, в командах
ниже меняй `neurootdel` на `edgelab`.

## Шаг 3. Разреши вход по коду в ChatGPT

Это нужно сделать один раз.

1. Открой ChatGPT в браузере.
2. Нажми на свой профиль, открой «Настройки», затем «Безопасность».
3. Включи пункт про авторизацию кода устройства для Codex.

## Шаг 4. Войди в ChatGPT с сервера

Выполни на сервере команду:

```
sudo -u neurootdel -H bash -lc 'HERMES_HOME=/home/neurootdel/.hermes /home/neurootdel/.hermes/hermes-agent/.hermes/bin/hermes auth add openai-codex --type oauth --no-browser'
```

Команда покажет ссылку и короткий код. Открой ссылку на телефоне или компьютере, войди в свой ChatGPT и введи код.
Когда вход пройдёт, в терминале появится сообщение об успехе.

Вход делаешь ты сам и только со своим аккаунтом ChatGPT. Пароль от ChatGPT на сервер не попадает: Hermes хранит
только ключ входа, и лежит он в `/home/neurootdel/.hermes/auth.json`, открытом только для пользователя агентов.

## Шаг 5. Запусти Аудитора

```
sudo systemctl restart hermes-auditor hermes-auditor-bridge
systemctl is-active hermes-auditor hermes-auditor-bridge
```

Обе строки ответа должны быть `active`. Проверь, что защиты включены:

```
sudo -u neurootdel -H bash -lc 'HERMES_HOME=/home/neurootdel/.hermes /home/neurootdel/.hermes/hermes-agent/.hermes/bin/hermes plugins list'
```

В списке должны быть включены `factcheck`, `secretguard` и `readonly`.

## Шаг 6. Первый разговор

Напиши своему новому боту в Telegram:

```
Прочитай файл ~/.hermes/SOUL.md и в двух строках скажи, что ты проверяешь и чего никогда не делаешь.
```

Аудитор прочитает свою роль и ответит. Отвечать он будет только тебе: установщик записал твой Telegram ID в
список разрешённых.

Почему просим прочитать файл: проверка фактов пропускает ответ с цифрами и утверждениями только тогда, когда
Аудитор в этом же ходе открыл источник. Если он ответит «Ответ задержан проверкой перед отправкой», значит
защита сработала. Попроси его сначала открыть нужный файл или страницу.

## Шаг 7. Отдай Аудитору работу Jarvis

Напиши Jarvis:

```
Отдай Аудитору на проверку свой последний отчёт. Дай ему путь к файлу и спроси, всё ли в нём подтверждается.
```

Jarvis отправит задачу командой `auditor-ask.py`. Через несколько минут в его чат придёт сообщение
«Ответ Аудитора», и Jarvis перескажет тебе вывод.

Ответ Аудитора всегда в одном виде:

```
Вывод: принято / есть дефекты / не проверено.
Доказательство: что открыл и что увидел.
Риск: что будет, если оставить.
Следующий шаг: кто и что делает.
```

## Какие задачи давать Аудитору

- «Аналитик прислал недельный отчёт. Сверь цифры с самой статистикой.»
- «Пройди воронку по слову ГАЙД как новый подписчик и скажи, где человек может застрять.»
- «Coder говорит, что бот настроен. Проверь, что он правда отвечает.»
- «Посмотри этот пост перед публикацией: факты, ссылки, обещания.»

Чем точнее ты скажешь, какой результат правильный, тем полезнее проверка.

## Как устроена защита

- **Только чтение.** Аудитор не может править файлы: инструменты записи у него выключены, а система открывает ему
  домашнюю папку только на чтение. Даже если его попросят «поправь сам», он опишет дефект и передаст его дальше.
- **Проверка фактов.** Ответ с цифрами, статусами и утверждениями уходит, только если в этом же ходе Аудитор
  прочитал источник.
- **Пароли и ключи.** Если в ответе окажется пароль, токен или ключ, ответ остановится целиком.
- **Роль закрыта на запись.** Свою роль Аудитор поменять не может. Менять её можешь ты: файл
  `/home/neurootdel/.hermes/SOUL.md`. После правки начни с ботом новый разговор командой `/new`.

## Если что-то не так

| Что видишь | Что сделать |
|---|---|
| Бот молчит | `systemctl is-active hermes-auditor`. Если не `active`, посмотри журнал: `sudo journalctl -u hermes-auditor -n 50` |
| В журнале ошибка входа или «401» | Повтори шаг 4, потом `sudo systemctl restart hermes-auditor` |
| Модель не найдена | Выбери модель из своей подписки: `sudo -u neurootdel -H bash -lc 'HERMES_HOME=/home/neurootdel/.hermes /home/neurootdel/.hermes/hermes-agent/.hermes/bin/hermes model'`, потом перезапусти службу |
| Вход по коду не проходит | Проверь шаг 3: пункт про код устройства для Codex должен быть включён |
| Jarvis отправил задачу, ответа нет | `python3 /usr/local/lib/neurootdel/auditor-ask.py --status <номер задачи>` покажет, где она. Журнал моста: `sudo journalctl -u hermes-auditor-bridge -n 50` |
| Аудитор слишком часто пишет «Ответ задержан проверкой» | Проси его открывать источник: файл, страницу, поиск. Это и есть его работа |

Если Аудитор упал, Richard узнает об этом сам: его сторож следит за службами Аудитора и пришлёт тебе сообщение.

## Как выключить

Остановить Аудитора и мост:

```
sudo systemctl disable --now hermes-auditor hermes-auditor-bridge
```

Включить обратно:

```
sudo systemctl enable --now hermes-auditor hermes-auditor-bridge
```

Приостановить только приём задач от агентов, бот при этом продолжит отвечать тебе:

```
sudo -u neurootdel touch /home/neurootdel/var/lib/auditor-bus/STOP
```

## Проверь себя

- [ ] Бот Аудитора отвечает в Telegram только тебе.
- [ ] `systemctl is-active hermes-auditor hermes-auditor-bridge` выдаёт два `active`.
- [ ] В `plugins list` включены `factcheck`, `secretguard`, `readonly`.
- [ ] Jarvis отдал Аудитору задачу, и в его чат пришёл «Ответ Аудитора».

## Проверка в конце дня

Запусти на сервере:

```
sudo neurootdel-verify
```

Команда проверит всё, что поставлено на твоём этапе, и напишет по строке на каждый пункт: ✅ сделано,
❌ нужно поправить, под каждым ❌ подсказка. Для этого урока смотри блок «Auditor (Hermes)»: служба работает,
вход ChatGPT сделан, свой бот отвечает, ты в списке доступа, роль и плагины на месте, мост работает.
День закончен, когда все строки с ✅.
