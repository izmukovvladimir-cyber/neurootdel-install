# Урок: свой бот для каждого агента

У каждого агента в твоём AI-отделе свой бот в Telegram. Через этого бота агент получает твои сообщения и
отвечает тебе. Два агента на одном боте мешают друг другу, поэтому одного бота на двоих делать нельзя.

Установщик без ботов дальше не пойдёт. Он проверит каждый токен через Telegram и попросит ввести его снова,
если токен с ошибкой или уже занят другим агентом.

## Сколько ботов нужно

| Этап | Агенты | Ботов |
|---|---|---|
| Мастер-класс | Jarvis, Richard | 2 |
| Интенсив | ещё Coder и Auditor | ещё 2, всего 4 |

Боты для интенсива можно создать сразу, а можно перед интенсивом. Бот, созданный заранее, просто ждёт.

## Шаг 1. Открой BotFather

1. В Telegram найди `@BotFather`. У настоящего рядом с именем синяя галочка.
2. Нажми «Запустить» или отправь `/start`.

## Шаг 2. Создай бота

Повтори этот шаг для каждого агента своего этапа.

1. Отправь BotFather команду `/newbot`.
2. BotFather спросит имя. Имя видно в чате, его можно писать по-русски. Например:
   - «Мой Jarvis»
   - «Мой Richard»
   - «Мой Coder»
   - «Мой Аудитор»
3. BotFather спросит адрес (username). Адрес пишется латиницей, без пробелов, и обязательно заканчивается на
   `bot`. Например `anna_jarvis_bot`, `anna_richard_bot`, `anna_coder_bot`, `anna_auditor_bot`. Если адрес
   занят, BotFather попросит другой: добавь цифру или своё имя.
4. BotFather пришлёт сообщение с токеном. Токен выглядит так: `1234567890:AAH...` (цифры, двоеточие, длинная
   строка из букв).

## Шаг 3. Скопируй токен

1. Нажми на токен в сообщении BotFather, Telegram скопирует его целиком.
2. Сохрани токен в заметки на своём телефоне или компьютере и подпиши, чей он: «токен Jarvis», «токен Richard».
3. Токен никому не пересылай и в чаты с агентами не вставляй. Кто знает токен, тот управляет ботом.

Потерял токен или случайно показал его кому-то: в BotFather отправь `/mybots`, выбери бота, нажми
«API Token», затем «Revoke current token». Старый токен перестанет работать, BotFather пришлёт новый.

## Шаг 4. Узнай свой id в Telegram

Установщик спросит твой числовой id, чтобы боты отвечали только тебе.

1. Найди в Telegram `@userinfobot` и нажми «Запустить».
2. Он пришлёт строку `Id: 123456789`. Сохрани это число.

## Шаг 5. Введи токены в установщик

Мастер-класс:

```
sudo bash /root/neurootdel-install.sh --stage workshop
```

Интенсив (Jarvis и Richard уже стоят, добавляются Coder и Auditor):

```
sudo bash /root/neurootdel-install.sh --stage intensive
```

Установщик спросит токен каждого бота по очереди. Пока ты вставляешь токен, его не видно на экране, это
нормально. После каждого токена установщик напишет `bot verified: @адрес_бота`.

Если токен уже записан на сервере (ты запускаешь установщик повторно), просто нажми Enter, он останется.

Установщик попросит токен ещё раз, если:

- токен скопирован не целиком: проверь, что есть двоеточие и длинная часть после него;
- этот бот уже отдан другому агенту: создай отдельного бота в BotFather;
- Telegram не узнал токен: скопируй его из BotFather заново.

## Шаг 6. Проверь ботов

1. Открой каждого бота в Telegram по его адресу и нажми «Запустить».
2. Напиши ему «привет». Агент ответит после того, как ты войдёшь в Claude по шагу из итоговой подсказки
   установщика.

## Проверка в конце дня

Запусти на сервере:

```
sudo neurootdel-verify
```

Команда проверит всё, что поставлено на твоём этапе, и напишет по строке на каждый пункт: ✅ сделано,
❌ нужно поправить. Под каждым ❌ написано, как его починить. Для этого урока смотри строки «свой бот отвечает
Telegram (getMe)» и «владелец в списке доступа бота» у каждого агента. День закончен, когда все строки
с ✅. Команду можно запускать сколько угодно раз, она ничего не меняет на сервере.
