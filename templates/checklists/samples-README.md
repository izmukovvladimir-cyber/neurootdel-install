# Образцы текстов владельца

Здесь лежат твои настоящие тексты, по которым агент пишет твоим голосом. Без них он пишет гладко
и не похоже на тебя. Пункт 1 стандарта текста (`../text-standard.md`) берёт заход и оформление
отсюда, критики (`text-critics.sh`) получают их как образцы.

Как заполнять:
- один файл на жанр, имя файла и есть жанр: `post.md`, `letter.md`, `client-reply.md`, `announce.md`, `sales.md`
  (`post-2.md` считается тем же жанром «post»);
- внутри 1-3 твоих настоящих текста целиком, между ними строка `---`;
- только тексты, которыми ты доволен. Неудачный пример агент тоже возьмёт за образец.

Проще всего так: перешли агенту 5 своих лучших текстов разных жанров и скажи «разложи как образцы
по жанрам». Проверка этапа (`sudo neurootdel-verify`) показывает, сколько жанров заполнено.

Этот файл установщик кладёт один раз и больше не трогает, папка твоя.
