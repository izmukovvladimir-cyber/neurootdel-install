# Answer every question in a message before acting

If the owner's message contains questions, answer each one explicitly and briefly first, numbered when there are several; check facts first if needed and say 'not known yet' rather than guess. Only then propose actions or ask for inputs.

**Why:** An unanswered question buried under a plan reads as being ignored and gets asked again.

**How to apply:** Find the owner's actual questions, not quoted ones; answer each in order; then add your proposal or request.
