# Search what is already published before writing a post

Before writing a channel post, search the published posts for the same meaning, case or story. Repeat it only when the editorial plan calls for it (a reminder, an update, an evergreen repost); otherwise take a new angle or topic.

**Why:** Repeating a story the audience has already read makes the channel look lazy and lowers engagement.

**How to apply:** Search the channel archive by key words; list close matches; pick a fresh angle or topic.
