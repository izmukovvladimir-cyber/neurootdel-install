# Deliver content ready to post, with a caption to copy

Unless the owner asked for another format, finished visual content goes in postable form: the image or video files themselves, each with a ready caption in a copyable block (one per platform if they differ). A preview page or a bundle with captions buried inside is used only when requested.

**Why:** The owner has to unpack and reassemble the material, which is exactly the work they delegated.

**How to apply:** Send each file; under it the caption in a code block; label platforms; state what is needed from the owner.
