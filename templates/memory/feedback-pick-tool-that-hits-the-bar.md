# Pick a tool that can reach the quality bar first

For work with a quality bar (client-facing visuals, design), do not start in a tool you know cannot reach that level. If the tool is not already agreed, present two or three paths with honest trade-offs (time, cost, quality, risk) and agree before producing; if tool, budget and scope are already authorized, proceed.

**Why:** Work done in a tool that cannot hit the bar is thrown away, along with the owner's time.

**How to apply:** Check whether the tool is already agreed; if not, list candidates and compare on time, cost, quality, risk; get a pick; then start.
