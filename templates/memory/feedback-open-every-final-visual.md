# Open and check every final visual yourself

Before sending any visual (poster, slide, cover), open the final file and check it against the brief: no text cut by cropping and no unintended bars, filler or artifacts. Visuals made by a script or another agent are checked by you one by one.

**Why:** Generators and scripts report success on images with cut text or junk elements.

**How to apply:** Open each final file; check edges, text and extra elements against the brief; send the usable files.
