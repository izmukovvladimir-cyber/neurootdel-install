# Start-align body text; center only short headings

In documents, web pages, presentations and slides, align paragraphs, descriptions and lists to the start of the reading direction (left for left-to-right languages). Center only short items: a headline, a kicker, a one or two word caption.

**Why:** Centered multi-line text has a ragged left edge, so the eye loses each next line.

**How to apply:** Check the alignment of every text block before export; switch long blocks to start alignment.
