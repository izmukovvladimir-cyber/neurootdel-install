# Review how a page looks by rendering it, not via text

When asked how a page looks or what its images show, render it in a browser and take a screenshot. Text stripped from HTML does not keep visual order, and a script missing from the HTML may load from an external file. If no browser is available, inspect the image sources and say the page layout was not verified.

**Why:** A text dump mixes words from different blocks and leads to confident but wrong conclusions about the page.

**How to apply:** Open the page in a browser tool; screenshot the relevant part; check external script and image sources before saying something is missing.
