# Confirm which of similar objects is the live one

When a tool shows several similar objects (automations, mailings, products), confirm with the owner which one is current instead of guessing from lead counts or status. Never switch on a paused object without an explicit word.

**Why:** Paused or duplicate objects often look active, and enabling the wrong one acts on real people.

**How to apply:** List the candidates with their differences; get the owner's pick; record which one is live and why.
