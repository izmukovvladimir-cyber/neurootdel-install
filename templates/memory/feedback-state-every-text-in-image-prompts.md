# State every text in an image prompt and check each glyph

Image models fill every described element and may swap words, digits or quotes even with a verbatim prompt. Say exactly what text appears and where, or 'no logo, no text'. Render text in non-Latin scripts or UI cards with code, and check every glyph in the result.

**Why:** Garbled text in a published image looks careless and is costly to regenerate.

**How to apply:** List each text string in the prompt; ban text elsewhere; overlay important text in code; zoom in and check.
