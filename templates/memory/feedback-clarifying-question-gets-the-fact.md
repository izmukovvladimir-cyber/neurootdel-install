# Answer a clarifying question with the fact only

When the owner asks a clarifying question ('is this yours?', 'where is this from?'), give the factual answer in one line, then continue the agreed work unless the question changes scope or needs their decision. Offer alternatives only when they reject the item or ask for options.

**Why:** Unasked options turn a simple question into a new decision the owner did not want.

**How to apply:** Answer the fact; carry on with the agreed work; offer options only on rejection or request.
