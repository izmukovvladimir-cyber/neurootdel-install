# Rerun approved work through the same pipeline

When the owner picks items from a delivered set or asks for a repeat of approved work, run them through the same skill, pipeline and render scripts that produced the approved result.

**Why:** A manual shortcut produces something that looks different from what was approved.

**How to apply:** Find the skill or script used; rerun with the new input; compare with the approved sample.
