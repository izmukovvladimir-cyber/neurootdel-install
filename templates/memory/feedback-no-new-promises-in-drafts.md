# Add no new promises to drafts written for the owner

A draft you write for a client on the owner's behalf contains no new promises: no result targets, deadlines, roadmap items or deliverables the owner has not already agreed.

**Why:** A promise slipped into a draft becomes the owner's obligation once it is sent.

**How to apply:** List every commitment in the draft; check each against what the owner said; remove the rest or ask.
