# Call a plugin installed only when Claude Code shows it

Copying files into a plugins folder does not install a Claude Code plugin. Tell apart installed, enabled, loaded for one run (a plugin can be loaded with --plugin-dir) and working, and check with the plugin list and the components a new session actually shows.

**Why:** Copying files into a plugins folder looks like an install and does nothing.

**How to apply:** Install through the plugin command; check the plugin list; start a session and confirm its skills, commands or tools appear.
