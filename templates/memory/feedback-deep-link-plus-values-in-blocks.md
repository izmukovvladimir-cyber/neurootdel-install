# Give web-panel steps as a deep link plus value blocks

Any step a person must do in a web panel starts with a clickable link to the exact section when a stable link exists and you have checked it; otherwise give the menu path. Every value they must type or paste (id, name, command, address) goes in its own fenced code block.

**Why:** Navigating from the home page and copying from running text causes wrong clicks and stray spaces.

**How to apply:** Open the direct URL of the section to check it, or write the menu path, never a session-specific link; one code block per value; say which field each value goes into.
