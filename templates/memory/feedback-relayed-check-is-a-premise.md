# Treat a check relayed by someone else as a premise

A verification relayed by a third party is a premise, not a check. Before acting on it, state which exact object the check had to cover and confirm the relayed one is that object.

**Why:** Relayed checks often covered a similar but different thing, and the error then lands in live data.

**How to apply:** Name the object the check must cover; ask or look which one was checked; verify yourself if they differ.
