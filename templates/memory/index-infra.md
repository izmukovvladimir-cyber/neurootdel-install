# Agents, server, infrastructure

What goes here: agents and their roles, the server, services, keys (names only, never values), cron, failures and their causes.

Line format: `- [title](file.md) - the gist in one line`.
Note names: `feedback-*.md` (behaviour rule), `reference-*.md` (reference, fact, where things are),
`project-*.md` (a matter or task with context). The note lives in this same directory.
