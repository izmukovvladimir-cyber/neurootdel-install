# Never claim a confirmation you do not have in front of you

When an earlier promise ('I will ask X') is still open and there is no reply from X, say plainly there is no answer yet. Never state that something was checked or confirmed by someone unless their message is in front of you.

**Why:** An invented confirmation is the fastest way to lose trust, and decisions get built on it.

**How to apply:** Look for the actual reply; quote it if present; otherwise write 'no answer yet' and when you will check again.
