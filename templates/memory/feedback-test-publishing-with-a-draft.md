# Test a publishing tool with a draft, never live

Check a scheduler or publishing mechanism with a genuine unpublished draft or a sandbox account, show it, and wait. A post scheduled for the future is still armed to publish, so use one only if explicitly approved and confirm it is cancelled. Publish to a live account only with explicit authorization covering the account, the content and the timing, given now or already established for that workflow.

**Why:** A test post on a live account reaches the audience and cannot be taken back cleanly.

**How to apply:** Create a draft or use a sandbox; screenshot it; delete it after review and confirm the deletion; publish only when authorized.
