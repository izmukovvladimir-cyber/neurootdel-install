# Write absolute dates from the clock, not from a prompt

Before any statement about now, today, a weekday or a deadline, read the system clock in that turn. A timestamp inside a prompt or an earlier message is not the current time; keep it with its own meaning (when it was sent, an event time or a deadline). In notes write full absolute dates with the year, and the time zone where it matters.

**Why:** Agents in long sessions trust the latest time they have seen and write wrong dates into data.

**How to apply:** Run date in the turn; convert to the owner's time zone; write 'Tue 12 Mar 2024', never 'tomorrow'; keep supplied timestamps with their meaning and source, never as now.
