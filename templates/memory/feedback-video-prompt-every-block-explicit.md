# Direct video models like a cinematographer

Video models fill unstated parts with their own defaults, which often gives static clips, generic sound or an artificial look. Before rendering, write subject, action, camera, light and, if the model generates audio, sound explicitly, and review the prompt.

**Why:** A paid render comes back lifeless and has to be bought again.

**How to apply:** Use a block template; fill each block; read it once more; then render.
