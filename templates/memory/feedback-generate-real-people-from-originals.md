# Generate a real person only from original photos

For a real person's likeness, use original photos as the identity reference in the form the tool recommends, never a previously generated image (generated images may serve only as composition or style references). Drop beauty anchors, keep the scene simple, and compare the result with the original before sending.

**Why:** Generated references and beautifying prompts drift the face until the person is no longer recognisable.

**How to apply:** Collect original photos; write a plain prompt and generate; compare side by side; reject drifted results.
