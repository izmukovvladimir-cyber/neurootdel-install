# Proofread every public text in full before it goes live

Before deploying any text people will read (bot messages, posts, mailings, site copy), read it in full: every sentence finished, no doubled words, grammar agrees, names, numbers and links match the source, no rude or overly familiar openers.

**Why:** A broken sentence or wrong link in a live bot reaches every person who passes through it.

**How to apply:** Read the final text top to bottom; check each number and link against the source; fix and read again.
