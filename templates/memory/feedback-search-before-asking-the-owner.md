# Search existing chats and memory before asking

Before asking the owner to forward something or explain a past decision, search where it would already be: shared memory, the work chats, task cards, shared drive links. Ask only if it is absent, and say where you looked.

**Why:** Asking for what is already in reach costs the owner time and makes the agent look forgetful.

**How to apply:** Search memory and chats by key words; check task cards; if still missing, ask one question with options and name the places you checked.
