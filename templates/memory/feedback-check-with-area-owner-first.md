# Check with the owning colleague before redefining its area

Before rewriting a procedure in an area someone else owns (another agent or a person: deploy, DNS, servers, integrations), confirm how it actually works and what the owner already decided. Ask the owner through the team's usual channel; if there is none, read the existing docs or ask the user.

**Why:** Advice built on a guess about someone else's area contradicts decisions you never saw.

**How to apply:** Find who owns the area; read its docs and decisions; ask the owner if unclear; then propose.
