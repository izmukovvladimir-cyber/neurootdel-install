# After a restart, compare what was built with what was sent

First thing after a service restart or session reset, compare the artifacts produced before it with the messages and files actually sent. An item built but not delivered is sent only if it was approved, is still wanted and has no delivery evidence; if delivery is uncertain, check or ask instead of resending.

**Why:** Finished work that never reached the person looks done in your notes while they are still waiting.

**How to apply:** List outputs from before the restart; check sent messages and delivery logs; send approved, still-relevant missing items; ask about uncertain ones and note them in handoff.
