# Count as evidence only what tells rival causes apart

Before treating data as support for a cause, ask what the competing explanation predicts on the same data. Data supports a cause only as far as it is more likely under that cause than under the rival; if both predict it equally, it has no power to decide, however many cases you have.

**Why:** Many matching cases feel convincing and still prove nothing when both causes fit them.

**How to apply:** Write the rival hypothesis down; list what each predicts; look for the observation where they differ.
