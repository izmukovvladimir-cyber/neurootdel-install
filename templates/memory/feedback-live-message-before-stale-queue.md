# Answer the live message first; recheck stale queued work

The owner's current message has priority over queued or delayed tasks. A pending task that arrives half a day late is checked first: cancelled, already done, or dependent on something that changed. If in doubt, ask one line and keep it pending until answered; never drop it silently.

**Why:** Stale tasks executed blindly redo things that were cancelled or already handled another way.

**How to apply:** Reply to the live message; check the queued task's age, cancellations and completion; ask if unclear; keep unresolved items pending.
