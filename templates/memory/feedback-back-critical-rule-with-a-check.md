# Back a critical rule with a mechanical check

A correction recorded as a note is the baseline. A critical rule (money, messages to people, a mistake that repeated) also gets a mechanical carrier: a check in the script, a hook or a gate that runs without the agent remembering it.

**Why:** Notes are forgotten after resets and compaction; a check in code runs every time.

**How to apply:** Write the note; find the code path; add a gate with a test; ask the code owner if it is not yours.
